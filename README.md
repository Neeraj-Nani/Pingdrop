# PingDrop

Public pages for the **PingDrop** Android and macOS apps.

- **Privacy policy:** https://neeraj-nani.github.io/Pingdrop/

PingDrop connects an Android phone to a Mac: notifications, clipboard and file
transfer, over the local network or Bluetooth, end-to-end encrypted, with no server
and no account.

The privacy policy served here is the one referenced by the Google Play listing.
Edit `index.html` and push to update it — the URL stays the same.
